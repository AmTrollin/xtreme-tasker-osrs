# <span style="color:#DEB887">Overview</span>

* <span style="color:#778899">Roll randomized Combat Achievement, Collection Log, and Achievement Diary tasks</span>
* <span style="color:#778899">Progress through Easy, Medium, Hard, Elite, and Master tiers</span>
* <span style="color:#778899">Track your current task, elapsed time, completion date, requirements, and tier progress</span>
* <span style="color:#778899">Search, filter, and sort the full task list</span>
* <span style="color:#778899">Optional HUD overlay to keep your current task visible while playing</span>
* <span style="color:#778899">Compact View for a smaller plugin panel</span>

# <span style="color:#DEB887">Getting Started</span>

<span style="color:#778899">Open the Xtreme Tasker overlay. If importing progress from an existing account, go to Help → Sync before rolling your first task to import completed Combat Achievements and Achievement Diaries.</span>

<span style="color:#778899">Collection Log item progress is refreshed automatically whenever you open your in-game Collection Log. This updates the underlying Collection Log data used by Xtreme Tasker, but does not automatically mark tasks as complete. Instead, any newly eligible Collection Log tasks will appear in the Help → Sync review panel alongside Combat Achievement and Achievement Diary tasks for you to review and apply manually.</span>

<span style="color:#778899">Then, just head to Current tab to roll your first task!</span>

<img src="docs/gifs/RollTask.gif" alt="Open overlay, complete a task, and roll a new one" width="550">

# <span style="color:#DEB887">Features</span>

### <span style="color:#DCDCDC">Current Task</span>

<span style="color:#778899">View requirements, open relevant wiki pages, track elapsed time, and roll your next task after completion. You can also choose which task types are included when rolling new tasks in the configuration panel. </span>

<img src="docs/images/CurrentTab.png" alt="Current Task" width="550">

### <span style="color:#DCDCDC">Optional HUD Overlay</span>

<span style="color:#778899">Keep your current task visible without leaving the game.</span><br>
<img src="docs/images/HUD.png" alt="HUD" width="240">

### <span style="color:#DCDCDC">Task List</span>

<span style="color:#778899">Browse the full task list with search, filtering, sorting, and progress tracking. Open any task to view requirements, completion progress, detailed information, and relevant wiki links.</span>

<img src="docs/images/TasksTab.png" alt="Task list" width="550">

### <span style="color:#DCDCDC">Account Sync</span>

<span style="color:#778899">Import completed Combat Achievements and Achievement Diaries into Xtreme Tasker, then review the proposed task completions before applying them. Account Sync also identifies tasks that no longer meet in-game requirements, helping keep your plugin progress accurate.</span>

<span style="color:#778899">Collection Log progress is refreshed automatically whenever you open your in-game Collection Log. This updates the underlying Collection Log data used to evaluate task completion. Any newly eligible Collection Log tasks are also added to the Help → Sync review panel and must be manually marked complete.</span>

<img src="docs/images/SyncTab.png" alt="Sync review" width="550">

<span style="color:#778899">When plugin adds new tasks, they'll appear in the Tasks tab with temporary indicators and a <strong>Show New Tasks</strong> filter.</span>

# <span style="color:#DEB887">Rules</span>

<span style="color:#778899">Xtreme Tasker follows the official Tasker ruleset with additional rules for the expanded task list. See the full <a href="docs/RULES.md" style="color:#4682B4; text-decoration:underline">Xtreme Tasker Rules</a>.</span>

<span style="color:#778899">Grandmaster Combat Achievements are included in the <strong>Master</strong> tier.</span>

<br>

# <span style="color:#DEB887">Privacy</span>

<span style="color:#778899">Xtreme Tasker stores progress locally in your RuneLite profile and mirrors it to RuneLite config for compatibility. No account progress or gameplay data is sent to external services.</span>

<span style="color:#778899">Sync only reads data already available to RuneLite, such as Combat Achievements, Achievement Diaries, skill progress, and Collection Log entries that have been viewed in-game. Collection Log data is refreshed automatically when the Collection Log interface is opened. No tasks are automatically completed.</span>
