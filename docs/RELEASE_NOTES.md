# Xtreme Tasker Release Notes

## 06.21.2026 - v2.0

## Xtreme Tasker Update

### Improved Sync & Completion Workflow

- Syncing now reviews potential task completions before making changes, giving you more control over what gets updated.
- Added tools to review and resolve sync mismatches between your plugin progress and in game progress.
- Added an Undo option for your most recently completed current task.
- Improved handling for sequential and repeatable tasks during syncs.

### Collection Log Improvements

- Collection Log tasks now display progress more clearly, including total obtained progress where applicable.
- Added better item icons, obtained-state indicators, and hover information.
- Collection Log syncing can now pick up progress from additional in game sources.
- Improved support for Ancient pages and several specialized Collection Log tasks.
- Reduced lag when opening and browsing Collection Log pages.

### Better Task Details & Prerequisites

- Prerequisites are now easier to read and understand.
- Added visual indicators for completed prerequisites and task requirements.
- Task completion states are more clearly highlighted throughout the interface.
- Added support for task tips.

### Interface & Quality-of-Life Updates

- Improved layouts and navigation across task lists, Current Task view, and sync review screens.
- Added support for skipping tasks.
- Improved scrolling, formatting, tooltips, and general interface consistency.
- Updated various counters, labels, and configuration options for clarity.

### Task Updates

- Improved progression and ordering for several task chains and sequential task groups.
- Added new Shellbane gryphon tasks.
- Updated and cleaned up numerous task names, requirements, and progression rules.
- Fixed several task-specific syncing and tracking issues.

### Performance & Stability

- Improved overall plugin responsiveness and reduced lag in several commonly used screens.
- Fixed issues that could occur when using Xtreme Tasker alongside Collection Log Master.
- Added extensive testing and reliability improvements to help prevent sync and progression issues.
