# <span style="color:#DEB887">What's New</span>

### <span style="color:#DCDCDC">Expanded Task Sources</span>

<span style="color:#778899">Xtreme Tasker rolls from three task sources:</span>

- <span style="color:#778899">Combat Achievements</span>
- <span style="color:#778899">Collection Log slots</span>
- <span style="color:#778899">Achievement Diaries</span>

<span style="color:#778899">The active Roll Source plugin setting controls whether you roll from every source, Combat Achievements only, or Collection Logs and Achievement Diaries only.</span>

### <span style="color:#DCDCDC">Combat Achievement Tiers</span>

<span style="color:#778899">Combat Achievements follow their in-game tier placement, with one plugin specific adjustment:</span>

- <span style="color:#778899">Grandmaster Combat Achievements are included in the Master tier.</span>

### <span style="color:#DCDCDC">Boss Combat Training Allowance</span>

<span style="color:#778899">For any task requiring that you kill a boss with a suggested skills section on that boss's strategies page on the OSRS Wiki, you may train your combat skills up to those suggested skill levels.</span>

<span style="color:#778899">This training must be done through Slayer. You may choose any slayer master or combination of slayer masters.</span>

<span style="color:#778899">It is heavily recommended to be strategic when choosing slayer masters for supplies and equipment throughout the grind. For example, Krystilia's slayer list includes mammoths, which can drop single dose prayer potions. That can be useful for boss tasks that require overhead prayers.</span>

### <span style="color:#DCDCDC">Account Sync</span>

<span style="color:#778899">Xtreme Tasker can sync supported account progress into the plugin, but sync exists to catch already completed progress. It does not change the rules for how tasks should be completed after they are rolled.</span>
